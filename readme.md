# BillBuddy

BillBuddy is a simple bill splitter that works out what everyone owes in seconds. Enter the total, choose a tip, and it shows each person's share in rupees (₹). You can split the bill evenly between a number of people, or add what each person ordered and let the tip be shared in proportion to their food. There is also an option to round every share up to the next whole rupee.

You can try it live at https://its-nihad.github.io/bill-spliter/

The project is two plain HTML files with no libraries and no build step. index.html is the landing page and home.html is the splitter itself. Everything runs in your browser, and nothing you type is saved or sent anywhere. To run it yourself, download both files into the same folder and open index.html.
